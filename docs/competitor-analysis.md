## 关键发现

### 1. 我们都有的（核心能力有）
- 上传文件、去重、格式统一、筛选、汇总、导出新文件

### 2. 我们不该缺的（基础功能）
- **原始数据预览**：上传后不展示数据内容，用户不知道自己有什么
- **排序**：最简单的需求，没有
- **处理结果预览**：执行完只给结论文字，不给表格展示
- **多轮对话**：一次完事不能接着问

### 3. 可以后续加的高级功能
- 图表（需要引入 matplotlib/echarts）
- 透视表
- 跨表合并
- 条件格式

## 建议的 MVP 功能集

按用户看到的东西来排：

**上传后**：
1. 显示文件名、Sheet名、行数列数 ✅ 已有
2. **显示原始数据前几行 🔴 缺**
3. 用自然语言说明发现了什么问题（"日期列格式不统一""发现2行重复"）🔴 缺，现在显示的是技术代码

**用户输入**：
4. 输入框 + 推荐示例 🔴 缺
5. 输入后直接执行，不经过"计划"页面 ✅ 方向A

**高风险操作**：
6. 弹窗确认影响范围 🔴 缺，现在是两步点击

**执行后**：
7. **展示处理后的数据表格 🔴 缺**
8. 汇总结果直观展示 🔴 缺
9. 下载按钮 ✅ 已有
10. **继续提问输入框 🔴 缺**

**基础功能缺失**：
11. 排序 🔴 缺
12. 缺失值处理（填充/删除） 🔴 缺
13. 按列拆分 🔴 缺
