# 表析 Agent 设计规格

## 1. 产品定位

表析 Agent 是面向普通办公人员的通用 Excel 分析智能体。用户上传一个或多个 Excel 文件，用自然语言描述需要完成的工作；系统先理解表格并展示可确认的执行计划，再完成清洗、分析、对比或改表，最后交付可下载的新 Excel 和可追溯的分析结果。

第一版只处理 Excel 及 CSV 文件，不将 Word 或 PDF 纳入主流程。后续可将 Word/PDF 作为分析口径、制度或业务说明的辅助材料，但不影响第一版的核心闭环。

## 2. 目标用户与价值

目标用户是需要日常处理表格、但不擅长公式、透视表、数据清洗或跨表核对的普通办公人员。

产品的核心价值是把“看懂陌生表格、确定处理步骤、实际修改文件、核对结果”压缩成一次自然语言协作，并让每项重要结果都可被复核。

## 3. 第一版范围

### 3.1 支持的输入

- 单个或多个 `.xlsx`、`.xls`、`.csv` 文件。
- 多工作表工作簿。
- 含公式、常见格式、合并单元格和空行的办公表格。

### 3.2 核心任务

1. 数据体检：识别工作表、表头、字段类型、数据量、空值、重复项、格式异常、字段缺失和疑似异常值。
2. 清洗与修复：统一日期、金额和文本格式，去重，拆分或合并字段，补充公式，生成规范数据表。
3. 分析与汇总：分组统计、筛选、排序、排名、占比、趋势、异常识别和汇总工作表生成。
4. 多表对比与合并：按用户指定或系统推荐的关键字段寻找新增、删除和变化项，或合并多个工作簿形成主表。

### 3.3 明确不做的内容

- 不承诺识别扫描版 PDF、图片或复杂 OCR 表格。
- 不自动覆盖用户上传的源文件。
- 不在用户未确认的情况下执行删除、批量覆盖或批量填充等高影响操作。
- 不把开放式行业知识问答作为第一版功能。

## 4. 用户体验与流程

```text
上传 Excel 文件
  -> 文件解析与表格体检
  -> 用户描述任务
  -> Agent 生成执行计划
  -> 用户确认高影响步骤
  -> 表格执行器处理数据
  -> 输出结果校验
  -> 结论卡片、可追溯明细和新 Excel 下载
```

### 4.1 工作台布局

- 左侧是文件与工作表列表，显示工作簿、工作表和基础数据量。
- 中间是任务对话区，展示用户需求、澄清问题、执行计划和处理进度。
- 右侧是数据预览区，展示表格体检、处理前后对比、结论卡片及每个结论的来源明细。

### 4.2 关键交互

上传完成后，系统先展示表格体检，不要求用户预先理解文件结构。用户输入任务后，Agent 将任务拆成可读的步骤，说明使用的字段、清洗动作、计算口径、将生成的工作表以及高影响改动的范围。

用户确认后才执行会删除数据、覆盖工作表或批量写入公式的操作。普通筛选、只读统计和预览可直接执行。完成后，结果页提供：

- 摘要结论卡片。
- 前后变化统计。
- 可展开的来源、筛选条件、公式和数据行定位。
- 下载处理后 Excel 文件的入口。

## 5. 技术架构与边界

### 5.1 文件解析器

职责：读取 Excel/CSV 文件，解析工作簿、工作表、表头、字段类型、公式、合并单元格和质量问题，输出统一的表格元数据与可预览数据。

依赖：文件存储和表格解析库。

### 5.2 任务规划器

职责：将自然语言请求转为受约束的操作计划。计划包含目标数据集、字段映射、步骤、计算口径、预计输出和是否需要用户确认。

依赖：表格元数据、用户对话上下文和大模型。

规划器不能直接修改文件，也不能跳过确认策略。

### 5.3 表格执行器

职责：按已确认计划执行数据清洗、筛选、计算、合并、对比、公式写入和工作表生成，并创建新的输出工作簿。

依赖：经过校验的操作计划和表格数据。

执行器不依赖大模型生成的任意代码；它只接受系统定义的、可验证的操作类型和参数。

### 5.4 结果审计器

职责：记录每一步使用的输入工作表、字段、筛选条件、公式、影响行数和输出位置；对输出文件进行基本质量校验。

依赖：执行日志和输出工作簿。

审计记录是结果追溯、结论解释和异常提示的唯一依据。

### 5.5 模型责任边界

大模型负责理解用户意图、生成受约束计划、解释数据和生成结论文本。实际的数据计算、文件修改和输出校验由确定性的表格能力完成，避免模型直接改写文件导致不可控结果。

## 6. 错误处理与安全策略

- 文件无法解析、格式不支持或工作表为空时，说明原因并保留文件，不生成虚假结果。
- 字段含义或匹配键不明确时，提出单个关键澄清问题或给出推荐选项，不自行选择可能错误的口径。
- 删除、覆盖原工作表、批量填充和写入公式属于高影响操作，必须展示影响范围并等待用户确认。
- 输出完成后，系统重新检查工作簿是否可打开、目标工作表是否非空、公式是否存在明显错误、关键行数变化是否与计划一致。
- 源文件始终保留，处理结果以新文件形式下载。

## 7. 演示数据与比赛展示

为证明通用性，准备三组不绑定特定行业的模拟数据：

1. 人员信息台账：含重复人员、联系方式或证件格式不统一及空值。
2. 项目进度表：含日期格式混乱、状态值不规范和延期风险分析任务。
3. 月度收支明细与预算目标：含金额文本化、分类不一致和跨表预算差异计算任务。

比赛现场以一份文件完成“体检 -> 自然语言任务 -> 计划确认 -> 新 Excel 下载”的完整闭环；其余两份表只展示不同任务类型，以证明产品不依赖固定场景。

推荐主讲任务：

> 帮我检查数据问题，统一格式并去重；按部门汇总；把处理结果和问题清单生成到一个新的 Excel。

## 8. 验收标准

第一版达到以下标准才可作为比赛演示版本：

1. 能上传并解析常见 Excel/CSV 文件，展示工作表、字段与数据质量概况。
2. 能完成至少一项清洗、一项汇总分析、一项跨表对比和一项公式补充任务。
3. 每次写操作都产出一个新的 Excel 文件，源文件不被覆盖。
4. 对高影响操作展示明确的影响范围并要求确认。
5. 重要结论可查看所依据的工作表、字段、筛选条件、公式或处理步骤。
6. 面对不支持文件、空文件、歧义指令和执行失败时，给出明确、诚实且可操作的提示。

## 9. 后续扩展

在第一版可稳定运行后，再增加以下能力：

- Word/PDF 规则材料解析，并将其中的指标口径用于 Excel 分析。
- 可编辑的报告模板和 Word/PDF 分析报告导出。
- 用户自定义常用数据清洗规则和分析模板。
- 更复杂的图表、透视分析和跨轮任务历史。
