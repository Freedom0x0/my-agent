## 背景

本任务在已完成的 antd-x 组件化重构基础上，进一步落实"豆包 / Codex 风格"的视觉与交互细节，并把"会话状态隔离"、"sender 的 @/ 触发"、"流式输出 stop 按钮"等关键交互落实。

参考产品视觉：豆包、Codex — 浅色背景、克制圆角、细边框、无多余装饰、留白充足。

---

## 视觉基线

- 背景：`#fafaf9` 或 `#f7f7f5`（暖白），卡片 `#ffffff`，边框 `#e5e5e5`（1px），圆角 `8px`（克制）
- 字体：默认 sans-serif 栈，字号 14 / 13 / 12
- 阴影：仅在弹出层/拖拽时使用，平时几乎无阴影
- 装饰：去掉色块、大标题图标背景；icon 用 antd `Outlined` 系列，统一 16px

## 需求

### 1. 左栏（历史任务）

布局（自上而下）：

```
┌─────────────────────────┐
│ [+ 新工作任务]            │  ← 全宽按钮，主色或深色文字 + 浅色背景
├─────────────────────────┤
│ 历史任务                  │  ← 分组标题（12px 灰字）
│ ┌─────────────────────┐ │
│ │ 当前会话1  ⋯        │ │  ← hover 显示三点
│ │ 当前会话2  ⋯        │ │
│ │ ...                 │ │
│ └─────────────────────┘ │
│   (滚动列表)             │
├─────────────────────────┤
│ 🧑 gsr  设置 ⚙           │  ← 底部用户区
└─────────────────────────┘
```

具体要求：

- **+ 新工作任务按钮**：占据顶部，全宽，主色文字 + 浅色背景（不用 primary fill），点击调用 `createSession()`
- **历史任务分组标题**：左侧 12px 灰字（color: `--text-secondary`），上下 padding 12/8
- **会话列表**：
  - 单行省略（`overflow: hidden; text-overflow: ellipsis; white-space: nowrap`）
  - hover 显示三点图标（`MoreOutlined`，点击弹出 Popover 菜单：重命名 / 删除）
  - 选中态：浅色背景（`#eef2f7` 或类似），左侧可选 2px 主色边
- **底部用户区**：左侧头像（圆形）+ 用户名，右侧设置图标按钮
- 可折叠：折叠后侧栏宽度变 0，中间占满；折叠状态持久化
- 可伸缩：拖拽侧栏右边缘调整宽度（最小 240，最大 480，默认 280），持久化

### 2. 中间栏（对话区）

布局：

```
┌─────────────────────────────┐
│                             │
│   消息流（滚动）             │
│                             │
│                             │
│   ┌───────────────────────┐ │
│   │ @文件  /命令           │ │  ← 输入区（Sender）
│   │                       │ │
│   │                       │ │
│   │              [发送]    │ │  ← 流式时变 [停止]
│   └───────────────────────┘ │
└─────────────────────────────┘
```

具体要求：

- **消息流**：使用 antd x `Bubble.List`，user / assistant 区分样式
  - 新会话无消息时：空状态居中展示 `Welcome`（品牌+一句话描述）+ `Prompts` 推荐任务卡片
  - 暂只展示 Excel 相关推荐（4 个卡片，点击触发 sendMessage）
- **输入框**：
  - 使用 antd x `Sender`
  - 支持 `@` 触发文件引用（弹出 Popover 列出当前 session 已上传文件，点选插入文件名 token）
  - 支持 `/` 触发命令菜单（最少实现 `/clear`、`/new`，其它可后续扩展）
  - **发送按钮在流式输出时变为"停止"按钮**：点击调用 store 里的 `abortCurrentStream()`，后端通过 SSE 取消
- **文件卡片出现在消息流里**：用户上传文件后，消息流里追加一条 user message（content 为 Attachments 列表）+ 一条 assistant message（"已收到文件 X，请告诉我你想做什么"）
- **拖拽文件到中间栏**（可选，本轮不做，写入下一轮）

### 3. 右栏（文件预览器）

布局：

```
┌─────────────────────────┐
│ [tab1 ×][tab2 ×][tab3 ×]│  ← 横向滚动，超出可滚
├─────────────────────────┤
│                         │
│   Excel 表格预览         │
│   (固定表头，H/V 滚动)    │
│                         │
└─────────────────────────┘
```

具体要求：

- **Tab 栏**：每个打开的文件一个 tab，标签显示文件名（省略），右侧关闭按钮（`CloseOutlined`）
- Tab 超出容器宽度：横向滚动（CSS overflow-x: auto + scrollbar 样式）
- Tab 内容：使用现有 `Previewer` 组件渲染 Excel（表头固定，H/V 滚动）
- **空状态**：无 tab 时显示居中提示"暂无打开的文件"+ 次级文案"上传或打开文件后将在此处预览"
- 可折叠：折叠后宽度 0，中间占满
- 可伸缩：拖拽左侧边缘调整宽度（最小 280，最大 720，默认 380），持久化

### 4. 会话状态隔离

- **Tab 状态按 session 隔离**：右栏 tab 列表以 sessionId 为 key 存储在 zustand store
- 切换会话：右栏自动切换到该 session 的 tab 列表（包括当前激活的 tab）
- store 形状：`tabsBySession: Record<sessionId, Tab[]>`, `activeTabBySession: Record<sessionId, string>`
- 持久化（localStorage）：tabsBySession 必须 persist（不然刷新页面 tab 没了）

### 5. 流式输出

- 后端返回 SSE 事件，前端在 store 里维护 `streamingContent` 字段
- 渲染：assistant 气泡的 content 直接绑定到 `streamingContent`，**不重建 DOM**
- 实现要点：
  - 单条 streaming message 用稳定的 React `key`
  - 流式过程中只更新 store 里的文本字段，React 自动 diff 文本节点（不重渲染气泡容器）
  - 发送按钮在 `status === "processing"` 时变"停止"，点击调用 `abortStream()`

### 6. 新会话初始态

- 调用 `createSession()` 后：
  - 中间栏：显示空状态（Welcome + Prompts 推荐任务）
  - 右栏：tab 列表为空，显示空状态提示
  - 上传文件：自动给该 session 创建一个 tab，并在中间消息流加一条 file 卡片
- 拖拽文件到会话：暂不实现（写入下一轮）

### 7. 切换会话

- 点击左栏会话：中间 + 右栏同时切换到该会话的状态
- 中间：messages 数组从 store 加载
- 右栏：tab 列表从 `tabsBySession[sessionId]` 加载
